# RISC-V CPU / VGA表示システム

参考にした書籍は「RISC-Vで学ぶコンピュータアーキテクチャ完全入門」Verilog HDLで記述した32ビット・5段パイプラインCPUと、メモリマップドI/O（MMIO）経由で描画するVGA表示システムです。Nexys A7-100Tを対象とし、CPUがフレームバッファに書き込んだ画素を640×480のRGB444形式で出力します。

トップモジュールは `scr_VGA/vga_top.v` の `vga_top` です。CPUがプログラムを実行して画素を書き込み、VGA回路が画面メモリを走査して表示します。

## 現在の開発状況

| 項目 | 状況 |
| --- | --- |
| CPU | 5段パイプライン、フォワーディング、ロード依存ストール、分岐予測を実装 |
| VGA表示回路 | 640×480・RGB444のフレームバッファと同期信号生成を実装 |
| CPUからの描画 | MMIO経由でフレームバッファへ書き込み可能 |
| 描画プログラム | 32×32ドットの文字を2倍に拡大して3文字描画する処理 |
| 初期データ | 風景用の長方形データ。現在の文字描画プログラムとは形式が不一致 |
| ピン制約 | Master XDCのVGA端子は設定済み。クロックとリセットの設定が必要 |

このリポジトリにはRTLとメモリ初期化データを収録しています。実機用ビルドには、描画データの整合とVivado側のIP・制約設定が必要です。

## システム構成

```text
CLK100MHZ → clk_wiz_0 ┬→ CPU用60 MHz → m_proc9_F
                     │                 ├→ 命令メモリ ← asm.vh
                     │                 ├→ データRAM  ← data.vh
                     │                 └→ MMIO ┬→ VGA制御レジスタ
                     │                         └→ フレームバッファ書き込み
                     └→ 画素用25 MHz → VGAタイミング生成
                                        └→ フレームバッファ読み出し → VGA出力
```

### CPU

- IF（命令フェッチ）、ID（デコード）、EX（実行）、MA（メモリアクセス）、WB（書き戻し）の5段構成。
- 32ビット×32本のレジスタ。`x0` の読み出し値は常に0。
- 演算結果のフォワーディング、ロード直後の依存によるストール、分岐予測ミス時の後続命令の無効化。
- 5ビットの分岐履歴と32個の2ビット飽和カウンタを使うgshare、および32エントリのBTB。
- 命令メモリは1,024ワード（4 KiB）。未指定部分は `nop`（`0x00000013`）で初期化。
- データRAMは16,384ワード（64 KiB）。非同期読み出し・クロック同期書き込み。
- `x30` への有効な書き戻し値を32ビットの `r_dout` に保持。

ALUには加減算、論理演算、左右シフト、算術右シフト、符号付き／符号なし比較を実装しています。条件分岐は `BEQ`、`BNE`、`BLT`、`BGE`、`BLTU`、`BGEU` を判定します。ロード／ストアは32ビットワード単位の実装です。

RISC-V命令形式を使用していますが、RV32I全体への準拠は保証していません。`JAL` / `JALR` のジャンプ制御、`AUIPC` のPC相対演算、バイト／ハーフワードのロード・ストア、例外・割り込みなどは未対応です。

### VGA

- 表示領域は640×480画素、1画素はRGB各4ビットの12ビット色。
- 水平800クロック、垂直525ラインのタイミングを生成。25 MHz設定時のフレーム周波数は約59.52 Hz。
- フレームバッファは8,192画素×38バンクで構成し、有効範囲は307,200画素。
- CPU側とVGA側で別クロックを使用し、画素読み出しの1クロック遅延に同期信号を合わせます。
- フレームバッファの初期値は黒。トップではCPUの画素書き込みとVGA側の読み出しを接続しています。

## メモリマップ

| アドレス | 用途 | データ形式・動作 |
| --- | --- | --- |
| `0x0000_0000` ～ `0x0000_FFFF` | データRAM | 32ビットワード単位で読み書き |
| `0x8000_0000` | 赤レジスタ | 下位4ビット |
| `0x8000_0004` | 緑レジスタ | 下位4ビット |
| `0x8000_0008` | 青レジスタ | 下位4ビット |
| `0x8000_000C` | X座標レジスタ | 下位10ビット、リセット値216 |
| `0x8000_0010` | Y座標レジスタ | 下位10ビット、リセット値208 |
| `0x8100_0000` ～ `0x8112_BFFF` | フレームバッファ | 4バイト境界のアドレスへ画素を書き込み |

画素 `(x, y)` の書き込み先は次の式で求めます。最終画素のアドレスは `0x8112_BFFC` です。

```text
アドレス = 0x81000000 + (y × 640 + x) × 4
書き込み値の下位12ビット = {R[3:0], G[3:0], B[3:0]}
例：黒 = 0x000、白 = 0xFFF、赤 = 0xF00
```

RGB・座標レジスタは読み書きできますが、現在のトップの画素出力には使用していません。表示色はフレームバッファから取得します。また、フレームバッファ内部にはCPU読み出しポートがありますが、トップでは未接続のため、CPUから画素を読み戻す機能は利用できません。

## 現在の描画プログラムとデータ

`asm.vh` は50命令からなる文字描画用プログラムです。

1. フレームバッファ全体を黒で消去。
2. データRAMから32ビット単位で文字の行データを読み出し、各ビットを検査。
3. 32×32ドットの文字を縦横2倍に拡大し、白い2×2画素として描画。
4. 左上座標 `(216, 208)` から、文字間隔72画素で3文字を描画。
5. 最後の条件分岐でループし、表示を保持。

一方、現在の `data.vh` は風景を描くための66個の長方形データ（330ワード）です。1個の長方形を `x, y, width, height, RGB444` の5ワードで表しています。

**現在の命令とデータの形式は一致していません。** この組み合わせでは、風景や意図した文字の表示は保証できません。文字を描画するには `data.vh` を3文字分の32×32ビットマップ（96ワード）に置き換えるか、風景を描画するには `asm.vh` を長方形データに対応した描画処理へ変更する必要があります。

## Vivadoでの準備

1. Nexys A7-100T向けのプロジェクトを作成します。
2. `scr_CPU/` と `scr_VGA/` の `.v` ファイルをDesign Sourcesに追加し、`vga_top` をトップに設定します。バックアップ内の同名モジュールは追加しないでください。
3. `asm.vh` と `data.vh` をインクルードファイルとして参照できるよう、リポジトリ直下をインクルード検索先に設定します。
4. Clocking Wizardで、モジュール名 `clk_wiz_0` のIPを作成します。入力100 MHz、`clk_out1` が25 MHz、`clk_out2` が60 MHzとなるよう設定し、アクティブHighの `reset` と `locked` ポートを有効にします。
5. `Nexys-A7-100T-Master.xdc` をConstraintsに追加します。VGA端子の14本（RGB各4本、水平・垂直同期各1本）は設定済みです。コメントアウトされている `CLK100MHZ` のピン割り当て（E3）と100 MHzクロック制約、`CPU_RESETN` のピン割り当て（C12）を有効にします。
6. 命令とデータの形式を合わせてから、合成・配置配線・タイミング確認・ビットストリーム生成を行います。

`nexys_a7.xdc` は旧LED構成用で、現在のトップに必要なVGA・リセットの制約を含みません。現在のトップにはLEDポートがないため、このファイルはビルド対象から外し、Master XDCに必要な制約をまとめてください。

Vivadoプロジェクト、Clocking WizardのIP設定・生成物、ビットストリームは含まれていません。60 MHz / 25 MHzはソース上の想定設定であり、実機動作や配置配線後のタイミング達成を示すものではありません。

## プログラムの変更方法

- 命令を変更するときは `asm.vh` の各要素に32ビットの命令語を設定します。命令メモリの要素番号はPCを4で割った値に対応します。
- 初期データを変更するときは `data.vh` の各要素に32ビット値を設定します。データRAMの要素番号に4を掛けた値がバイトアドレスになります。
- 文字描画を使う場合は、1文字を32ワードで表します。各ワードが1行に対応し、bit31が左端、bit0が右端です。3文字分を連続して配置します。
- 長方形データを使う場合は、5ワードずつ読み出して各矩形を塗りつぶすプログラムが必要です。

これらはハードウェアの初期化データです。FPGA上の初期内容を変更するには、変更を反映したビットストリームを生成して書き込みます。

## リセット

`CPU_RESETN` はアクティブLowです。ボタン入力またはクロックIPのロック解除からリセット要求を生成し、CPUクロック領域では非同期にリセットを要求、2段のレジスタを介して解除します。

CPUのリセットはPC、パイプライン状態、結果出力を初期化します。レジスタファイル、通常RAM、フレームバッファ、分岐予測器は宣言時の値や `initial` ブロックで初期化しており、ボタンリセットでは再初期化しません。現在のプログラムは再実行時に画面を黒で消去します。
